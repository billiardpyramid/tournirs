# Ближайшие турниры по русскому бильярду (пирамида)

Статический сайт со списком ближайших турниров по пирамиде (свободная, комбинированная,
динамичная, омка). Пул, снукер, карамболь, дартс и фишки не включены.

**Сайт:** https://billiardpyramid.github.io/tournirs/

## Что внутри

- `index.html` — сам сайт (основная страница). Собран в один файл: данные лежат в массиве
  `ROWS` внутри `<script>`, внешних зависимостей нет. В каждой строке 9 полей, последнее — URL
  страницы турнира на площадке-источнике.
- `billiard-tournaments.html` — тот же файл, для прямой ссылки по имени.

## Как устроен сайт

- Клик по строке турнира открывает его на площадке-источнике в новой вкладке.
  У ЛЛБ и B4Y это страница конкретного турнира, у МСБС — общий календарь
  (отдельных страниц у МСБС не существует).
- Поиск по названию/городу/клубу.
- Фильтр по региону: Москва / Санкт-Петербург / область / другой регион / за рубежом.
- Календарь: на широком экране — липкая панель справа; на узком (<1080px) — горизонтальная
  лента **в самом верху** страницы, над поиском и таблицей.
- Строки турниров чередуются по фону, при наведении — подсветка.
- Дни с 8 и более турнирами помечены звёздочкой.

## Источники данных

| Метка | Площадка | Что даёт |
|---|---|---|
| ЛЛБ | https://www.llb.su/tournaments/next | общероссийская лента турниров по всем регионам |
| МСБС | https://mosbilliard.ru/calen/ | официальный календарь Москвы и России |
| B4Y | https://bill4you.ru/rus-billiard | только пирамида, много любительских турниров |

## Обновление

1. Собрать свежие данные с трёх площадок.
2. Обновить массив `ROWS` в `index.html` и `billiard-tournaments.html`.
   В каждой строке 9 полей; последнее — URL страницы турнира:
   ЛЛБ `https://www.llb.su/t/<id>`, B4Y `https://bill4you.ru/rus-billiard/tournament/<id>`,
   МСБС — всегда `https://mosbilliard.ru/calen/`.
3. Закоммитить в ветку `Pyramid_tournirs` — страница обновится сама (GitHub Pages).
